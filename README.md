# Telecom Security Registry

React-приложение для учёта протоколов безопасности в телекоммуникациях: создание и редактирование записей, статусы, критичность и диаграммы.

**Примерный период реализации:** март — апрель 2026. Период указан по истории Git и отражает основную работу над проектом.

## Возможности

- Список записей, создание, просмотр, редактирование и удаление.
- Проверка обязательных полей и допустимых значений статуса и критичности.
- Диаграмма распределения записей по статусам и критичности.

## Стек

React, React Router, Axios, Recharts и Create React App.

## Локальный запуск

```bash
npm ci
npm start
```

Адрес REST API задаётся переменной `REACT_APP_API_URL`. По умолчанию используется демонстрационный MockAPI endpoint из `src/services/itemsApi.js`; для независимого запуска задайте собственный API с ресурсом записей.

```bash
REACT_APP_API_URL=http://localhost:3001/items npm start
```

Команда выше задаёт адрес API, но не запускает backend. `npm run build` создаёт сборку, `npm test` запускает тестовый runner.
